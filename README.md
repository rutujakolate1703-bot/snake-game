# 🐍 Snake Game (JavaScript)

A classic Snake Game built using **HTML, CSS, and JavaScript (Canvas)**.  
The game runs directly in the browser and includes modern features like speed increase, sound effects, dark/light mode, and persistent high score.

---

## 🎮 Live Features

- ⌨️ Keyboard controls (Arrow keys)
- 🍎 Food eating & snake growth
- 📈 Score counter
- 🏆 High score (saved using localStorage)
- ⚡ Speed increases as score increases
- 🌙 Dark / ☀️ Light mode toggle
- 🔄 Restart button
- 💀 Game over detection (wall & self collision)

---

## 🛠 Tech Stack

- **HTML5** – Game structure
- **CSS3** – Styling & themes
- **JavaScript** – Game logic
- **Canvas API** – Game rendering
- **localStorage** – High score persistence

---

## 🎯 How to Play

1. Open the game in a browser
2. Press any **Arrow Key** to start
3. Eat the red food  to grow
4. Avoid hitting the wall or yourself
5. Try to beat the **High Score** 🏆
